# 第三课：计算机基础与 goroutine

## 这节课讲什么

先建立进程、线程、CPU 核、地址空间、栈/堆和调度的直觉，再对比 C 的 pthread 与 Go goroutine。说明 goroutine 适合隐藏 I/O 等待，但不会自动消除共享数据和等待问题。

## 课堂安排

- 25 分钟：进程、线程、调用栈/堆和上下文切换；
- 20 分钟：C 线程和 Go runtime 调度的对比；
- 25 分钟：启动 goroutine、闭包捕获和顺序/并发输出；
- 25 分钟：并发执行任务并收集结果；
- 20 分钟：用 `go test -race` 观察共享变量问题；
- 5 分钟：故意不等待 goroutine，让结果缺失，转到 channel/sync。

## 讲解重点

用“谁产生结果、谁等待结果、谁拥有共享数据”三个问题检查每段并发代码。避免把 runtime 内部缩写讲成背诵内容，只保留能帮助学生读测试失败的概念。

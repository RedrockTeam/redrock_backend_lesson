## 一、提问的智慧

相信现在有很多同学已经走上了学习编程的这一条路，在这条路上难免会有很多问题。因此如何提问就成了一个必须学习的问题。学姐们不是机器人，面对许多同学的问题也是应接不暇的，是会累的。当你遇到一个自己无法解决的问题时，不要直接就把问题抛出来给学姐们进行解答。你们已经是一个成熟的大学生了，首先要学会自我解决问题。不要看到问题就去问别人，自我解决的能力要先去培养。

### 如何去解决问题呢？


1. 首先**善用浏览器**，遇到问题先在浏览器上找答案，现在互联网很发达，你出现的问题可能其他人也出现过很多人就会把他解决问题的方法发布在网上。（诸如CSDN、稀土掘金、StackOverflow、github都是很好的网站可以帮助你解决问题）。
2. 如果你实在是在网上找不到解决方法或者是看不懂如何操作，**可以试试神奇的ai**。现在AI很发达，在相当一部分情况下，ai会比学姐们讲得更简单易懂。除了Chat GPT可能需要魔法上网以外，其他的国内的AI也是很好的（文心一言、通义千问、科大讯飞、Kimi等等）。可以向AI询问你的问题，它或许可以帮你解决（但是请不要过于依赖AI）。

### 问题的类型


1. 代码问题：

* **算法**：先去看题解（因为学姐们也可能没做过这道题或者这种类型的题），题解能帮你们解决问题。如果实在是看不懂题解，请移步至AI，AI有时候甚至讲的比我们还要清晰。如果都没看明白，再请**将原题，你的代码和题解**一并发给学姐们，并指出你对哪一块地方不太懂。
* **项目作业问题**：如果是代码出现了报错，请学会自己定位问题，现在的开发软件很智能，会告诉你你的代码错在哪个文件的哪一行。你们可以通过报错去找出问题，如果看不懂，不要直接把问题发给AI，先尝试自己通过翻译软件得知报错问题（我们希望你们能够培养出自己解决问题的能力，不要过度依赖AI）。如果实在解决不了，再尝试交给AI。最后再来询问学姐们，并且将你出现**错误的代码**和**debug**（即终端报错）一并发给学姐们。


2. 配置安装问题

* 在开发中我们可能会安装很多外有库，如果在安装对应的外有库出现了问题，先去查阅外有库的官方文档，上面一般会统计常见的问题。如果无法解决，请善用搜索引擎，将你的问题在搜索引擎中输入，很大可能别人也出现了相同的问题，你就可以按照他们的方法去解决。（CSDN、稀土掘金、博客网、一些牛人的个人博客等等都可能可以帮你解决）。如果都不行再尝试去询问AI或学姐们

1. 请不要在吗起手，有问题直接问，学姐们看到就会回复，你一个在吗起手，学姐们忙的时候不会去搭理这种问题。
2. 问问题请把详细的问题和问题相关的截图一并发给学姐，**请不要拍屏幕发照片**，眼睛真的是会瞎的！ ![请选择你的拍屏阵营](image.png)

## 二、如何用好AI

AI 是非常有用的学习与开发辅助工具，但它不是万能的，正确使用能大幅提升效率，错误使用可能带来误导。


1. **AI的作用**：解释概念、排查错误、生成/补全代码及配置、重构优化代码、梳理文档需求、提供学习路径与思路。
2. **使用前准备**：说明环境（系统、语言/依赖版本等）、提供最小可复现代码、完整错误信息与堆栈、说明期望vs实际结果、列出尝试过的解决方法。
3. **提问方式**：简述背景（做什么、技术栈）、明确目标、提供输入（代码/错误）、说明约束（平台/版本限制）、指定期望输出形式。
4. **常用Prompt模板**：

* 调试：说明语言版本、错误堆栈、代码、期望结果，求分析及修复方案。
* 解释概念：用通俗语言解释，含示例、误区、适用场景。
* 代码优化：说明目标（可读性/性能等），求重构建议及示例。
* 生成测试：指定框架，覆盖正常及边界情况，说明运行方式。
* 环境问题：说明系统、错误、尝试过的方法，求解决步骤。
* 生成配置：指定语言/框架，说明要求，求可用文件及注意事项。


1. **安全与伦理**：不泄露敏感信息（密钥、隐私等）；作业/考试需诚信，以理解和独立完成为前提。
2. **整合流程**：用AI做首轮探索（获思路、样板等），自己动手验证，迭代优化prompt，记录建议便于复查。

## 三、GO语言基础语法

### go语言是什么

Golang(又称Go)是Google公司开发的一种**静态强类型、编译型、并发型**，并具有垃圾回收功能的编程语言。它经常被比喻成21世纪的C语言。Go作为Google2009年推出的语言，其被设计成一门应用于搭载Web服务器、存储集群或类似用途的巨型中央服务器的系统编程语言。

同时我们网校这边的后端，也是由Go去编写的。

接下来将讲解Go的基本语法内容。

### 程序结构基础

Go语言的程序由一个或多个源文件组成，每个源文件都以`.go`作为拓展名。源文件的第一行必须是`package`声明，指明这个文件属于哪个包，一般程序入口包为`main`。

### 简单Hello World程序

```go
// hello.go
package main // 声明该文件属于main包

import "fmt" // 导入fmt包，提供输入输出功能

func main() { // 定义main函数，是程序的入口点
    fmt.Println("Hello, world!") // 调用fmt包的Println函数，打印一行文本到标准输出
}
```

### 运行与编译命令


1. 直接编译并运行：

```bash
go run hello.go # 编译并运行这个文件
```


2. 编译生成二进制文件（持久化）：

```bash
go build hello.go # 编译并生成一个二进制文件
./hello # 执行这个二进制文件（Windows系统用 hello.exe）
```

## 包

包是Go语言的重要组成单位，设计目的是为了简化程序的设计和维护。

* 每个包都有独立的命名空间，通过全局唯一的导入路径标识
* 导入后通过`包名.`前缀访问包内内容
* 标准库包（如`fmt`）可直接导入，也可自定义包

### 自己编写一个包

#### 编写步骤


1. 创建目录（目录名默认作为包名，也可使用别名）
   * 别名导入格式：`import alias "package/path"`，使用时用`alias.`前缀
2. 目录内创建`.go`文件，第一行必须声明`package 包名`
3. 包内内容（变量、常量、类型、函数）需**大写字母开头**才能被导出（外部访问）
4. 其他文件通过`import "包路径"`导入（禁止循环调用）
5. 调用格式：`包名.导出内容`

#### 示例：编写circle包（计算圆的面积和周长）


1. 创建`circle`目录
2. 目录内创建`circle.go`：

```go
// circle.go
package circle // 声明该文件属于circle包

import "math" // 导入math包

const Pi = math.Pi // 定义常量Pi（大写导出）

// Area 计算圆的面积（大写导出）
func Area(r float64) float64 {
    return Pi * r * r // 面积公式：πr²
}

// Circumference 计算圆的周长（大写导出）
func Circumference(r float64) float64 {
    return 2 * Pi * r // 周长公式：2πr
}
```


3. 在`main.go`中导入使用（假设`circle`目录与`main.go`同级）：

```go
// main.go
package main

import (
    "fmt"
    "circle" // 导入自定义circle包
)

func main() {
    r := 10.0 // 半径
    fmt.Println(circle.Area(r))         // 调用面积函数，输出 314.159...
    fmt.Println(circle.Circumference(r))// 调用周长函数，输出 62.831...
}
```

### 包的匿名导入

在导入路径前添加下划线`_`，表示导入但不直接使用包内容，用于：

* 触发包的初始化行为（如注册驱动）
* 抑制`unused import`编译错误

格式：`import _ "package/path"`

### 常用标准库

#### 1. time包（时间处理）

提供时间获取、格式化、计算等功能：

```go
import "time"
import "fmt"

func main() {
    now := time.Now() // 获取当前时间
    fmt.Println(now)          // 打印完整时间
    fmt.Println(now.Year())   // 年份
    fmt.Println(now.Month())  // 月份
    fmt.Println(now.Day())    // 日期
    fmt.Println(now.Hour())   // 小时
    fmt.Println(now.Minute()) // 分钟
    fmt.Println(now.Second()) // 秒数

    tomorrow := now.Add(24 * time.Hour) // 当前时间加24小时（明天）
    fmt.Println(tomorrow)

    format := "2006-01-02 15:04:05" // 固定格式（Go的参考时间）
    fmt.Println(now.Format(format)) // 格式化输出
}
```

#### 2. strconv包（类型转换）

处理字符串与基本数据类型的转换：

```go
import "strconv"
import "log"
import "fmt"

func main() {
    s := "10"
    // 字符串转整数
    i, err := strconv.Atoi(s)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(i) // 输出 10

    // 字符串转64位浮点数
    f, err := strconv.ParseFloat(s, 64)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(f) // 输出 10.0

    // 字符串转布尔值（"1"→true，"0"→false，其他报错）
    b, err := strconv.ParseBool("1")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(b) // 输出 true

    // 整数转字符串
    s = strconv.Itoa(i)
    fmt.Println(s) // 输出 "10"

    // 浮点数转字符串（格式'f'=十进制，精度2）
    s = strconv.FormatFloat(f, 'f', 2, 64)
    fmt.Println(s) // 输出 "10.00"

    // 布尔值转字符串
    s = strconv.FormatBool(b)
    fmt.Println(s) // 输出 "true"
}
```

#### 3. fmt包（输入输出）

提供格式化输入输出功能，常用函数：

* **打印类**：`Println`（换行）、`Printf`（格式化）
* **字符串生成类**：`Sprint`（拼接）、`Sprintf`（格式化拼接）
* **输入类**：`Scan`（按空格读取）、`Scanf`（格式化读取）

示例：

```go
import "fmt"

func main() {
    x := 10
    y := 3.14
    z := "Hello"

    // 字符串生成
    s1 := fmt.Sprint(x, y, z)
    fmt.Println(s1) // 输出 "10 3.14 Hello"

    s2 := fmt.Sprintf("x=%d, y=%.2f, z=%s", x, y, z)
    fmt.Println(s2) // 输出 "x=10, y=3.14, z=Hello"

    // 输入读取
    var a int
    var b float64
    var c string
    fmt.Scan(&a, &b, &c) // 输入格式：10 3.14 Hello
    fmt.Println(a, b, c)

    fmt.Scanf("%d %f %s", &a, &b, &c) // 格式化读取
    fmt.Println(a, b, c)
}
```

## 变量

变量是存储数据的容器，包含名称和类型，遵循以下规则：

### 命名规则

* 由字母、数字、下划线组成，**不能以数字开头**
* 区分大小写（`x`和`X`是不同变量）
* 不能使用Go关键字（共25个）
* 不建议重定义预定义标识符（37个）

### 关键字（25个）

```

case     defer    go       map        struct
chan     else     goto     package    switch
const    fallthrough if     range      type
continue for      import   return     var
```

### 预定义标识符（37个）

```

// 类型

uint   uint8   uint16   uint32   uint64   uintptr
float32 float64 complex128 complex64
bool   byte    rune     string   error

// 函数
make    len     cap      new       append    copy     close    delete
complex real    imag
panic   recover
```

### 变量声明方式

#### 1. 标准声明（指定类型）

```go
var x int          // 声明整数变量x（零值初始化）
var y string       // 声明字符串变量y
var z bool = true  // 声明并赋值（类型可省略）
```

#### 2. 类型推断（省略类型）

```go
var x = 10         // 编译器推断为int
var y = "Hello"    // 编译器推断为string
```

#### 3. 批量声明

```go
// 单行批量
var x, y, z int

// 块级批量
var (
    a string  // " "（空字符串）
    b bool    // false
    c float64 // 0.0
)
```

#### 4. 短变量声明（简化语法）

* 用`:=`代替`var`和类型，仅用于**函数内**
* 只能声明新变量，不能重复声明

```go
func main() {
    x := 10        // 等价于 var x int = 10
    y := "Hello"   // 等价于 var y string = "Hello"
    x, y := 20, "World" // 批量声明新变量（或重新赋值已有变量）
    // x := 30 // 错误：重复声明
}
```

### 零值初始化

* 布尔类型：false
* 字符串类型：`""`（空字符串）
* 指针、函数、接口、切片、通道、映射：nil

## 函数

函数是代码复用的基本单位，用`func`关键字定义。

### 定义格式

```go
func 函数名(参数列表) (返回值列表) {
    // 函数体
    return 返回值
}
```

* 参数列表：`参数名 类型`，多个参数用逗号分隔（同类型可简写：`x, y int`）
* 返回值列表：可指定类型（多个返回值用括号包裹），也可命名返回值

### 示例

```go
// 普通函数（两个int参数，返回int）
func add(x int, y int) int {
    return x + y
}

// 简写参数类型（x和y均为int）
func sub(x, y int) int {
    return x - y
}

// 多个返回值（返回商和余数）
func divmod(x, y int) (int, int) {
    quotient := x / y
    remainder := x % y
    return quotient, remainder
}

// 命名返回值（自动初始化零值，return可省略参数）
func multiply(x, y int) (result int) {
    result = x * y
    return // 等价于 return result
}
```

## 分支与循环

### 分支结构

Go只有`if`和`switch`两种分支语句，无`else if`关键字（可嵌套`if`）。

#### 1. if/if-else

```go
// 示例1：单分支
x := 10
if x > 0 {
    fmt.Println("x is positive")
}

// 示例2：双分支
x := -10
if x > 0 {
    fmt.Println("x is positive")
} else {
    fmt.Println("x is negative")
}

// 示例3：多分支（嵌套if）
x := 5
if x < 3 {
    fmt.Println("small")
} else if x < 7 { // 实际是 else { if ... } 的简写
    fmt.Println("medium")
} else {
    fmt.Println("large")
}
```

#### 2. switch-case

* 无需`break`（默认自动break），如需穿透用`fallthrough`
* case可多个值，支持表达式

```go
x := 10
switch x {
case 1, 2, 3:
    fmt.Println("x is small")
case 4, 5, 6:
    fmt.Println("x is medium")
case 7, 8, 9:
    fmt.Println("x is large")
default:
    fmt.Println("x is unknown") // 输出此句
}

// 表达式switch（类似if-else）
switch {
case x > 0 && x < 5:
    fmt.Println("small positive")
case x >= 5 && x < 10:
    fmt.Println("medium positive")
default:
    fmt.Println("other")
}
```

### 循环结构

Go只有`for`循环（无`while`和`do-while`），可通过不同写法实现多种循环逻辑。

#### 1. 正常循环（初始化+条件+后置）

```go
// 打印0-9
for i := 0; i < 10; i++ {
    fmt.Println(i)
}
```

#### 2. 无限循环（无条件）

```go
// 死循环（需用break退出）
for {
    fmt.Println("Hello")
    // break // 取消注释可退出
}
```

#### 3. 类while循环（仅条件）

```go
i := 0
// 打印0-4
for i < 5 {
    fmt.Println(i)
    i++
}
```

#### 4. 类do-while循环（先执行后判断）

```go
i := 0
// 打印0-4
for {
    fmt.Println(i)
    i++
    if i >= 5 {
        break
    }
}
```

#### 5. for-range循环（遍历容器）

用于遍历数组、切片、映射、字符串等，返回索引（或键）和值：

```go
// 遍历切片
slice := []int{1, 2, 3, 4, 5}
for index, value := range slice {
    fmt.Printf("索引：%d，值：%d\n", index, value)
}

// 遍历映射
m := map[string]int{"a": 1, "b": 2}
for key, value := range m {
    fmt.Printf("键：%s，值：%d\n", key, value)
}

// 遍历字符串（返回索引和rune）
s := "Hello世界"
for i, r := range s {
    fmt.Printf("索引：%d，字符：%c\n", i, r)
}
```

## 容器

Go原生提供的常用数据结构，用于存储和管理多个元素。

### 数组（array）

* 固定长度的序列，定义后长度不可修改
* 值类型（赋值或传参时拷贝整个数组）
* 声明格式：`var 数组名 [长度]类型`

示例：

```go
// 声明长度为5的int数组（零值初始化：[0,0,0,0,0]）
var arr [5]int
arr[0] = 10 // 给第一个元素赋值
arr[1] = 20 // 给第二个元素赋值

// 声明并初始化
arr2 := [3]string{"a", "b", "c"}

// 自动推导长度
arr3 := [...]int{1, 2, 3, 4} // 长度为4
```

### 切片（slice）

* 动态数组（长度可变），引用类型（底层指向数组）
* 比数组更灵活，是Go中最常用的容器
* 声明格式：`var 切片名 []类型` 或 `切片名 := []类型{元素...}`

示例：

```go
// 直接初始化（长度=5，容量=5）
slice1 := []int{1, 2, 3, 4, 5}

// 从数组截取（左闭右开，长度=3，容量=4）
arr := [5]int{1, 2, 3, 4, 5}
slice2 := arr[1:4] // 包含arr[1], arr[2], arr[3]

// 用make创建（长度=3，容量=5）
slice3 := make([]int, 3, 5) // make(类型, 长度, 容量)

// 追加元素（容量不足时自动扩容）
slice3 = append(slice3, 4, 5)
```

### 映射（map）

* 键值对集合（哈希表实现），无序
* 键必须是可比较类型（如int、string，不能是切片、映射）
* 声明格式：`var 映射名 map[键类型]值类型` 或 `映射名 := map[键类型]值类型{键:值...}`

示例：

```go
// 声明并初始化
m1 := map[string]int{
    "apple":  1,
    "banana": 2,
    "cherry": 3,
}

// 用make创建（初始容量10）
m2 := make(map[int]string, 10)
m2[1] = "a" // 添加键值对
m2[2] = "b"

// 访问值（第二个返回值表示键是否存在）
v, exists := m1["apple"]
if exists {
    fmt.Println(v) // 输出 1
}

// 删除键值对
delete(m1, "banana")
```

## 结构体（struct）

结构体用于把若干字段组合成一个复合类型，适合描述实体对象和聚合数据。

### 定义格式

```go
type 名称 struct {
    字段名 字段类型
    // 可选：字段标签（用于 json、xml、orm 等）
    Age int `json:"age"`
}
```

* 字段可导出（首字母大写）或未导出（首字母小写）。
* 字段标签用反引号声明，常用于序列化或反射。

### 示例

```go
type Person struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

// 声明与初始化
var p1 Person               // 零值：{"", 0}
p2 := Person{Name: "Alice", Age: 30}
p3 := &Person{Name: "Bob"} // 指向结构体的指针
```

### 匿名字段与嵌入（embedding）

* 可以嵌入其它类型（匿名字段），实现类似继承的字段与方法提升（promoted）。

```go
type Address struct {
    City string
}

type Employee struct {
    Person      // 嵌入 Person，Person 的字段和方法被提升
    Address     // 嵌入 Address
    Position string
}
```

### 方法（绑定到结构体类型）

```go
// 值接收者
func (p Person) Greeting() string {
    return "Hello, " + p.Name
}

// 指针接收者（可修改接收者）
func (p *Person) HaveBirthday() {
    p.Age++
}
```

### 构造函数习惯用法

Go 没有构造函数语法，常用工厂函数：

```go
func NewPerson(name string, age int) *Person {
    return &Person{Name: name, Age: age}
}
```

### 注意点

* 大结构体传递时考虑使用指针以避免复制开销。
* 使用结构体标签与 encoding/json 等库配合进行序列化/反序列化。

## 指针（pointer）

指针保存变量的内存地址。Go 支持指针但不支持指针运算（如算术）。

### 基本语法

* & 获取地址，\* 解引用。

```go
x := 10
p := &x   // p 是 *int，指向 x
fmt.Println(*p) // 10
*p = 20
fmt.Println(x)  // 20
```

### new 与 make

* new(T) 返回 \*T，分配零值并返回指针。
* make 用于 slice、map、channel 的初始化，返回对应的已初始化对象（不是指针）。

```go
p := new(int) // 等价于 var x int; p=&x
*m = 0
s := make([]int, 0)
```

### 指针与结构体

常用方式传递结构体指针以便修改或避免复制：

```go
func UpdateCity(p *Person, city string) {
    p.Name = "X"    // 等价于 (*p).Name = "X"
    p.Age = 99
}
```

### nil 指针与安全

* 指针的零值为 nil，使用前要检查 nil，避免 panic。

```go
var p *Person
if p != nil {
    p.HaveBirthday()
}
```

### 接收者选择（值接收 vs 指针接收）

* 如果方法需要修改接收者或避免复制大对象，使用指针接收者。
* 为一致性，类型的多数方法应统一使用指针接收或值接收（避免混淆方法集）。

## 接口（interface）

接口是一组方法签名的集合，定义了类型应实现的行为。实现是隐式的：只要类型具有接口所需方法，就实现该接口。

### 定义格式

```go
type 接口名 interface {
    Method1(arg T) R
    Method2() error
}
```

### 示例

```go
type Stringer interface {
    String() string
}

func Print(s Stringer) {
    fmt.Println(s.String())
}

type Person struct { Name string }
func (p Person) String() string { return p.Name }

Print(Person{Name: "Tom"}) // Person 隐式实现 Stringer
```

### 空接口

* interface{} 表示任意类型（类似 any）。

```go
var x interface{}
x = 123
x = "hello"
```

### 类型断言与类型选择

* 类型断言获取具体类型或判断类型：

```go
var v interface{} = "abc"
s := v.(string)           // 断言，若失败会 panic
s, ok := v.(string)       // 安全断言
```

* 类型开关：

```go
switch t := v.(type) {
case int:
    // t 是 int
case string:
    // t 是 string
default:
}
```

### 接口值的内部表示与 nil 的陷阱

* 接口值内部包含 (type, value)。即便 value 为 nil，如果 type 非 nil，接口值不等于 nil。

```go
var p *Person = nil
var i interface{} = p
// i != nil，因为 i 的动态类型是 *Person（非 nil），value 为 nil
```

注意在比较接口是否为 nil 时需谨慎。

## 四、GO环境变量

在Windows系统中配置Go开发环境时，GOPATH、GOBIN、PATH、GOPROXY是四个核心环境变量，直接影响代码管理、编译输出、命令调用及依赖下载。以下详细说明Windows下的配置方法及作用。

### 1. GOPATH

#### 定义

GOPATH是Go语言的**工作目录路径**，用于统一管理Go项目的源码、依赖包和编译产物。

#### 作用

GOPATH目录下默认包含3个子目录（需手动创建或由Go自动生成）：

* `src`：存放项目源代码（.go文件），按包路径组织（如`src/github.com/用户名/项目名`）。
* `pkg`：存放编译生成的中间文件（.a归档文件），加速后续编译（避免重复编译依赖）。
* `bin`：若未配置GOBIN，`go install`生成的可执行文件默认存于此。

### 2. GOBIN

#### 定义

GOBIN是Go**可执行文件的输出目录**，用于指定`go install`命令生成的二进制文件的存放路径（覆盖GOPATH/bin的默认行为）。

#### 作用

* 若未配置GOBIN，`go install`生成的可执行文件默认存于`GOPATH/bin`。
* 配置后可自定义输出位置（如`D:\go_bin`），方便集中管理可执行文件。

### 3. PATH

#### 定义

PATH是Windows系统的**全局环境变量**，用于指定系统搜索可执行文件的路径列表。

#### 作用

在Go开发中，PATH的核心作用是：

* 让系统能直接识别Go的核心命令（如`go run`、`go build`）——需包含Go的安装目录。
* 让系统能直接运行GOBIN（或`GOPATH/bin`）中的可执行文件——无需输入完整路径。

#### 配置步骤


1. 找到Go的安装目录（默认是`C:\Program Files\Go\bin`，若自定义安装则需对应路径）。
2. 进入"环境变量"设置界面，在"用户变量"或"系统变量"中找到`Path`，点击"编辑"。
3. 点击"新建"，分别添加Go安装目录（如`C:\Program Files\Go\bin`）和GOBIN路径（如`D:\go_bin`）。
4. 点击"确定"保存所有设置。

#### 验证方法

打开cmd或PowerShell，输入`go version`，若输出Go的版本信息（如`go version go1.21.0 windows/amd64`），说明配置成功。

### 4.GOPROXY

#### 定义

GOPROXY是Go Modules的**代理服务器地址**，用于解决国内访问国外代码仓库（如GitHub）时下载慢、失败的问题。

#### 作用

代理服务器会缓存依赖包，加速下载过程，避免因网络问题导致的依赖获取失败。

#### 常用代理地址（国内推荐）

* 七牛云代理：`https://goproxy.cn`（稳定且常用，推荐使用这个）
* 阿里云代理：`https://mirrors.aliyun.com/goproxy/`

#### 配置步骤


1. 打开cmd或PowerShell。
2. 输入命令设置代理（全局生效）：

   ```cmd  
   go env -w GOPROXY=https://goproxy.cn,direct  
   ```

   （`direct`表示若代理不可用，直接访问原仓库，可选）

#### 验证方法

输入`go env | findstr GOPROXY`，若输出`GOPROXY=https://goproxy.cn,direct`，说明配置成功。

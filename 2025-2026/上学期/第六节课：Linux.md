# 第六节课：Linux

# Linux入门

## 1 Linux介绍

### 1.1 Linux是什么？

Linux 是一种自由和开放源码的类 Unix 操作系统，它在设计和功能上模仿了传统的 Unix 操作系统。

简单来说，你可以把它理解成与 Windows、macOS 类似的操作系统（OS），但它有着更灵活、更稳定、更安全的特性，尤其在服务器和开发领域占据主导地位。

### 1.2 Linux的应用场景

Linux 在 IT 世界中无处不在：

| 应用领域 | 描述  |
|------|-----|
| 服务器  | 最主要的用途。几乎所有的互联网巨头、云计算平台（如阿里云、腾讯云、AWS）和网络服务器都在使用 Linux。作为后端开发者，你会大量接触 Linux 服务器环境。 |
| 嵌入式设备 | 路由器、智能电视、车载系统等很多嵌入式设备都运行基于 Linux 内核的系统。 |
| 移动设备 | 你每天使用的 Android 操作系统就是基于 Linux 内核开发的。 |
| 超级计算机 | 世界上绝大多数最快的超级计算机都运行 Linux。 |
| 桌面系统 | 也可以作为日常使用的桌面操作系统。 |

### 1.3 Linux相对于windows的优势是什么？

* **稳定性与可靠性**：服务器需要常年不间断的运行，Linux具有极高的稳定性，长时间运行不需要重启，很少出现系统崩溃。
* **安全性**：权限管理机制更加严格和精细。
* **资源效率**：占用系统资源少，相同硬件下，Linux可以支持更多的用户请求或运行更多的服务。
* **命令行工具**：强大的 Shell (如 Bash) 和丰富的命令行工具集，可以轻松实现自动化任务和批处理操作。
* **自由开放**：源代码开放，可以自由修改和定制。
* **生态系统匹配**：绝大多数 Web 服务器、云计算平台、Docker 和 Kubernetes 等容器技术都是原生为 Linux 设计的。

### 1.4 如何使用Linux？

对于Linux的初学者来说，没有必要安装原生Linux系统，我们有更安全、更高效的方式来使用 Linux 环境，这些方案能让我们在保留 Windows 的便利性的同时，充分利用 Linux 的优势：

* **WSL（Windows Subsystem for Linux）**：可以在 Windows 中原生运行一个完整的 Linux 发行版（如 Ubuntu/Debian），可以直接运行 Linux 命令和编译 Go 程序，开发体验几乎与原生 Linux 一致。
* **虚拟机**：使用 VirtualBox 或 VMware 等软件，在 Windows 中运行一个独立的 Linux 系统。它不会影响你的主系统，可以随时快照、恢复和删除。
* **云服务器**：直接购买一台轻量级的云服务器（如阿里云、腾讯云），通过 SSH 远程操作。

### 1.5 虚拟机，wsl1，wsl2的比较

| 特性  | 传统虚拟机 (VM) | WSL 1 | WSL 2 (推荐!) |
|-----|------------|-------|-------------|
| 底层技术 | 完整的硬件虚拟化 (Hyper-V, VirtualBox, VMWare)。 | 兼容层，将 Linux 系统调用翻译成 Windows 系统调用。 | 轻量级虚拟化，运行一个真正的 Linux 内核。 |
| 内核  | 运行一个完整的、独立的 Linux 内核。 | 不包含真正的 Linux 内核，依赖于翻译层。 | 运行一个真正的、微软优化过的 Linux 内核。 |
| 系统隔离 | 完全隔离，拥有自己的文件系统、内存和网络。 | 共享，但系统调用是翻译的。 | 接近完全隔离，但共享网络接口。 |
| CPU/内存开销 | 较高。需要预先分配大量的 RAM 和 CPU 核心。 | 较低。动态分配 RAM，效率高。 | 较低。动态分配 RAM，效率高。 |
| 性能  | CPU 性能接近原生，但有轻微开销。 | 性能：文件 I/O (读写) 差。 | 性能：文件 I/O 极好，CPU 性能接近原生。 |
| 应用场景 | 需要运行完整桌面 GUI、测试不同操作系统、学习底层操作系统原理。 | 适合只需要简单运行 Bash 脚本和命令行工具的场景（已逐渐被 WSL 2 取代）。 | 最推荐！适合大多数场景。 |

### 1.6 Linux发行版是什么？

要将到Linux发行版，就要先从Linux的组成讲起，Linux系统的组成如下：

* **Linux系统内核**：提供最核心的功能，如内存管理、进程管理、设备驱动、文件系统和I/O管理等。
* **系统级的应用程序**：出场自带的程序。

由于Linux内核是开源的，所有人都可以通过访问 <https://www.kernel.org> 来下载Linux内核源码并且查看和修改。

这也就代表了：

* 任何人都可以修改内核，并自行集成系统级的应用程序。
* **内核+系统级应用程序的封装，称为Linux发行版。**

### 1.7 常见的Linux发行版介绍

基于包管理器，常见的Linux发行版大致可以分为两类：

| 派系名称 | 包管理系统 | 包格式 |

| Ubuntu | 最流行的发行版。基于 Debian，但更新更快、易用性极强，拥有最活跃的社区。 | 初学者、桌面开发、WSL 2 环境。 |

### 1.8 Linux的核心思想——一切皆文件

"一切皆文件"（Everything is a file）是 Unix 哲学中最核心、最优雅的设计思想，Linux把它继承了下来。

根据POSIX标准的定义，Linux文件可以分成七大类：

| 文件类型 | 介绍  | 示例  |
|------|-----|-----|
| 普通文件（Regular file） | 这是最常见的文件类型，用来存储数据。可以存储文本、二进制数据、源码等。 | `/etc/hosts` (配置文件), `/var/log/syslog` (日志文件), `/usr/bin/go` (可执行文件) |
| 目录文件（Directory File） | 目录本身也是一种特殊的文件。 | `/home/`, `/etc/`, `/tmp/` |
| 符号链接/软链接（Symbolic Link / Soft Link） | 类似于 Windows 上的"快捷方式"。它是一个指针，指向另一个文件或目录的路径，它不占用实际存储空间，删除软链接不影响原文件。 | `/usr/bin/python` 可能是一个指向 `/usr/bin/python3` 的软链接 |
| 块设备文件（Block Device File） | 代表可以以"块"为单位进行数据访问的硬件设备，如硬盘、SD卡、光驱等，数据访问是缓冲的。 | `/dev/sda` (第一块 SCSI/SATA 硬盘), `/dev/hda` (旧的 IDE 硬盘) |
| 字符设备文件（Character Device File） | 代表以"字符"为单位进行数据访问的硬件设备，如键盘、鼠标、串口、伪终端等，数据访问是非缓冲的。 | `/dev/tty` (当前终端), `/dev/null` (空设备，写入的数据被丢弃) |
| 命名管道文件（Named Pipe / FIFO） | 就像一根连接两个进程的水管，进程A向它写入数据，进程B从它读取数据，严格按照先进先出的顺序传输。命名管道用 `mkfifo` 创建。 | -   |
| 套接字文件（Socket File） | 用于实现同一台机器上不同进程之间的通信。 | `/var/run/docker.sock` |

### 1.9 Linux系统文件层次

从图片我们可以看出，在Linux中，所有文件和目录都挂载在根目录 `/` 之下，它是整个文件系统的最高层级。

根据FHS（文件系统层次结构标准）定义的最重要的一级目录及用途如下：

* `/bin` （Binaries）：系统启动和修复所需的必要可执行文件，面向所有用户。
* `/boot` ：存放引导加载程序所需文件，以及Linux内核映像文件。
* `/dev` （Device）:存放设备文件（块设备和字符设备），代表系统中所有硬件和虚拟设备。
* `/etc` （Et Cetera）:存放系统级别的配置文件和目录，如网络、服务、用户配置等。
* `/home` ：普通用户的家目录，存放个人的代码、配置、脚本等。
* `/lib` （Libraries）：存放 `/bin` 和 `/sbin` 中可执行文件所需的共享库文件。
* `/media` ：用于挂载可移动存储设备，如 USB 驱动器、光盘等，插入u盘后，文件通常出现在这里。
* `/mnt` （Mount）：用于临时挂载文件系统的空目录。
* `/opt` （Optional）：用于安装第三方、非系统必需的软件包。
* `/proc` （Processes）：虚拟文件系统，存放进程信息和内核状态。
* `/root` ：root用户的家目录。
* `/sbin` （System Binaries）：存放系统管理和维护所需的必要可执行文件。通常只有 root 用户才能执行。
* `/tmp` （Temporary）：存放程序运行时的临时文件。系统重启时文件会被清空。
* `/usr` （Unix System Resources）：存放大多数用户工具和应用程序，通常是只读的。
* `/var` （Variable）：存放可变数据文件。系统运行时经常变化的文件都在这里，如 `/var/log` 、 `/var/mail` 。

## 2 Linux命令

### 2.1 Linux命令介绍

Linux命令主要分为两大类：

* 外部命令/文件系统命令
* 内建命令

| 特点  | 内建命令 (Built-in) | 外部命令 (External) |
|-----|-----------------|-----------------|
| 存储位置 | Shell 程序内部      | 文件系统中的目录（如 `/bin`, `/usr/bin`, `/sbin` 等） |
| 执行方式 | 由 Shell 直接执行，无需创建新进程 | Shell 必须通过系统调用启动一个新的进程来执行该文件 |
| 执行速度 | 较快              | 较慢（因为涉及进程创建）    |
| 典型示例 | `cd`, `pwd`, `echo`, `alias`, `export`, `source` | `ls`, `grep`, `cp`, `mv`, `vim`, `go` |
| 主要用途 | 改变 Shell 进程的内部状态和环境 | 执行文件操作、复杂的逻辑处理和系统功能 |

为什么需要内建命令？因为像 `cd` 这样的命令需要直接改变 Shell 进程自身的运行状态（当前工作目录），如果它作为一个独立进程运行，它改变的目录只对它自己有效，而无法影响 Shell 的环境。

我们要学习一个命令，可以通过 `man [命令名]` 来获取它的信息。

### 2.2 目录与文件

#### 2.2.1 目录/文件操作

`**pwd**` ：打印工作目录的绝对路径。

`**cd**` ：改变工作目录

`cd` 命令的常用用法：

| 命令  | 描述  |
|-----|-----|
| `cd /path/to/dir` | 使用绝对路径移动到指定目录。 |
| `cd projects/api` | 使用相对路径移动到当前目录下的子目录。 |
| `cd ..` | 移动到当前目录的上一级目录（父目录）。 |
| `cd .` | 保持在当前目录（通常用于重新加载环境或查看当前目录文件）。 |
| `cd ~` | 移动到当前用户的家目录（最常用快捷方式）。 |
| `cd -` | 移动到上一次所在的目录。 |
| `cd` (不带参数) | 等同于 `cd ~` ，移动到当前用户的家目录。 |

`**mkdir**` ：创建新的目录

`mkdir` 命令的基本用法：

| 命令  | 描述  |
|-----|-----|
| `mkdir [目录名]` | 在当前工作目录下创建单个目录。 |
| `mkdir /path/to/dir` | 使用绝对路径或相对路径创建目录。 |
| `mkdir logs docs assets` | 一次创建多个目录。 |

`mkdir` 的常用选项：

| 选项  | 描述  | 示例  |
|-----|-----|-----|
| `-p` | 递归创建目录。如果父目录不存在则一并创建。 | `mkdir -p project/src/cmd` |
| `-m [模式]` | 设置目录的初始权限（模式是八进制数）。 | `mkdir -m 777 temp_dir` (所有人可读写执行) |

#### 2.2.2 文件/目录的查看和管理

`**ls**` :用于列出当前工作目录或指定目录下的文件和子目录。

`ls` 常见用法和选项：

| 命令  | 描述  | 示例  |
|-----|-----|-----|
| `ls` | 列出当前目录下的文件和目录（不包括隐藏文件）。 | `ls` |
| `ls /path/to/dir` | 列出指定目录的内容。 | `ls /etc` |
| `ls -l` | 长格式（long format）：显示文件类型、权限、硬链接数、所有者、所属组、大小、修改日期和文件名。 | `ls -l` |
| `ls -a` | 显示所有（all）文件，包括以 `.` 开头的隐藏文件（如 `.bashrc` ）。 | `ls -a` |
| `ls -h` | 人性化（human-readable）显示文件大小，如 `1.5M` 代替字节数，常与 `-l` 联用。 | `ls -lh` |
| `ls -t` | 按修改时间（time）倒序排序（最新修改的在前）。 | `ls -lt` |
| `ls -R` | 递归（Recursive）列出子目录中的内容。 | `ls -R project` |

`**touch**` 命令主要有两个作用：


1. 如果指定文件名不存在， `touch` 会创建一个大小为零（空）的新文件。
2. 如果指定的文件名已经存在， `touch` 会更新该文件的访问时间和修改时间，但不改变文件内容。

`touch` 命令的常用用法：

| 命令  | 描述  | 示例  |
|-----|-----|-----|
| `touch [文件名]` | 创建新的空文件，或更新现有文件的 atime 和 mtime 为当前时间。 | `touch server.go` |
| `touch file1 file2 log.txt` | 一次操作多个文件。 | `touch config.yml log.txt` |

`touch` 命令高级选项：

| 选项  | 描述  | 示例  |
|-----|-----|-----|
| `-a` | 只更新文件的访问时间 (atime)，不更新 mtime。 | `touch -a logs/access.log` |
| `-m` | 只更新文件的修改时间 (mtime)，不更新 atime。 | `touch -m main.go` |
| `-c` | 不创建 (no create) 文件。如果文件不存在，不创建新文件，也不报错。 | `touch -c non_exist.txt` |
| `-t [时间]` | 设置指定文件的时间戳为特定的 `[[CC]YY]MMDDhhmm[.ss]` 格式。 | `touch -t 202401011030.00 old_file` (设置为2024年1月1日10点30分0秒) |
| `-r [参考文件]` | 使用另一个参考文件的时间戳来设置目标文件的时间戳。 | `touch -r template.html index.html` (使 index.html 时间戳与 template.html 一致) |

`**cp**` 命令：用于将文件或目录从一个位置复制到另一个位置。

它有三种基本使用场景：


1. 文件 到 文件：将一个文件复制并命名为另一个文件。
2. 文件 到 目录：将一个文件复制到指定的目录下（保留原文件名）。
3. 目录 到 目录：将一个目录及其内容完整地复制到另一个目录中（需要使用递归选项）。

基本语法为：

```bash
cp [选项] [源文件或目录] [目标文件或目录]
```

| ------------ | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 底层技术     | 完整的硬件虚拟化 (Hyper-V, VirtualBox, VMWare)。                                                  | 兼容层，将 Linux 系统调用翻译成 Windows 系统调用。                                           | 轻量级虚拟化，运行一个真正的 Linux 内核。                                                              |
| 内核         | 运行一个完整的、独立的 Linux 内核。                                                               | 不包含真正的 Linux 内核，依赖于翻译层。                                                      | 运行一个真正的、微软优化过的 Linux 内核。                                                              |
| 系统隔离     | 完全隔离，拥有自己的文件系统、内存和网络。                                                        | 共享，但系统调用是翻译的。                                                                   | 接近完全隔离，但共享网络接口。                                                                         |
| CPU/内存开销 | 较高。需要预先分配大量的 RAM 和 CPU 核心。                                                        | 较低。动态分配 RAM，效率高。                                                                 | 较低。动态分配 RAM，效率高。                                                                           |
| 性能         | CPU 性能接近原生，但有轻微开销。                                                                  | 性能：文件 I/O (读写) 差。                                                                   | 性能：文件 I/O 极好，CPU 性能接近原生。                                                                |
| 应用场景     | 需要运行完整桌面 GUI、测试不同操作系统、学习底层操作系统原理。                                    | 适合只需要简单运行 Bash 脚本和命令行工具的场景（已逐渐被 WSL 2 取代）。                      | 最推荐！适合大多数场景。                                                                               |

### 1.6 Linux发行版是什么？

要将到Linux发行版，就要先从Linux的组成讲起，Linux系统的组成如下：

- **Linux系统内核**：提供最核心的功能，如内存管理、进程管理、设备驱动、文件系统和I/O管理等。
- **系统级的应用程序**：出场自带的程序。

由于Linux内核是开源的，所有人都可以通过访问 https://www.kernel.org 来下载Linux内核源码并且查看和修改。

这也就代表了：

- 任何人都可以修改内核，并自行集成系统级的应用程序。
- **内核+系统级应用程序的封装，称为Linux发行版。**

### 1.8 Linux的核心思想——一切皆文件

"一切皆文件"（Everything is a file）是 Unix 哲学中最核心、最优雅的设计思想，Linux把它继承了下来。

根据POSIX标准的定义，Linux文件可以分成七大类：

| 文件类型                         | 介绍                                                                                                         | 示例                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| 普通文件（Regular file）         | 这是最常见的文件类型，用来存储数据。可以存储文本、二进制数据、源码等。                                       | `/etc/hosts` (配置文件), `/var/log/syslog` (日志文件), `/usr/bin/go` (可执行文件) |
| 目录文件（Directory File）       | 目录本身也是一种特殊的文件。                                                                                 | `/home/`, `/etc/`, `/tmp/`                                         |
| 符号链接/软链接（Symbolic Link / Soft Link） | 类似于 Windows 上的"快捷方式"。它是一个指针，指向另一个文件或目录的路径，它不占用实际存储空间，删除软链接不影响原文件。 | `/usr/bin/python` 可能是一个指向 `/usr/bin/python3` 的软链接       |
| 块设备文件（Block Device File）  | 代表可以以"块"为单位进行数据访问的硬件设备，如硬盘、SD卡、光驱等，数据访问是缓冲的。                         | `/dev/sda` (第一块 SCSI/SATA 硬盘), `/dev/hda` (旧的 IDE 硬盘)   |
| 字符设备文件（Character Device File） | 代表以"字符"为单位进行数据访问的硬件设备，如键盘、鼠标、串口、伪终端等，数据访问是非缓冲的。                 | `/dev/tty` (当前终端), `/dev/null` (空设备，写入的数据被丢弃)     |
| 命名管道文件（Named Pipe / FIFO） | 就像一根连接两个进程的水管，进程A向它写入数据，进程B从它读取数据，严格按照先进先出的顺序传输。命名管道用 `mkfifo` 创建。 | -                                                               |
| 套接字文件（Socket File）        | 用于实现同一台机器上不同进程之间的通信。                                                                     | `/var/run/docker.sock`                                            |

### 1.9 Linux系统文件层次

从图片我们可以看出，在Linux中，所有文件和目录都挂载在根目录 `/` 之下，它是整个文件系统的最高层级。

根据FHS（文件系统层次结构标准）定义的最重要的一级目录及用途如下：

- `/bin` （Binaries）：系统启动和修复所需的必要可执行文件，面向所有用户。
- `/boot` ：存放引导加载程序所需文件，以及Linux内核映像文件。
- `/dev` （Device）:存放设备文件（块设备和字符设备），代表系统中所有硬件和虚拟设备。
- `/etc` （Et Cetera）:存放系统级别的配置文件和目录，如网络、服务、用户配置等。
- `/home` ：普通用户的家目录，存放个人的代码、配置、脚本等。
- `/lib` （Libraries）：存放 `/bin` 和 `/sbin` 中可执行文件所需的共享库文件。
- `/media` ：用于挂载可移动存储设备，如 USB 驱动器、光盘等，插入u盘后，文件通常出现在这里。
- `/mnt` （Mount）：用于临时挂载文件系统的空目录。
- `/opt` （Optional）：用于安装第三方、非系统必需的软件包。
- `/proc` （Processes）：虚拟文件系统，存放进程信息和内核状态。
- `/root` ：root用户的家目录。
- `/sbin` （System Binaries）：存放系统管理和维护所需的必要可执行文件。通常只有 root 用户才能执行。
- `/tmp` （Temporary）：存放程序运行时的临时文件。系统重启时文件会被清空。
- `/usr` （Unix System Resources）：存放大多数用户工具和应用程序，通常是只读的。
- `/var` （Variable）：存放可变数据文件。系统运行时经常变化的文件都在这里，如 `/var/log` 、 `/var/mail` 。

## 2 Linux命令

### 2.1 Linux命令介绍

Linux命令主要分为两大类：

- 外部命令/文件系统命令
- 内建命令

| 特点     | 内建命令 (Built-in)                                | 外部命令 (External)                               |
| -------- | -------------------------------------------------- | ------------------------------------------------- |
| 存储位置 | Shell 程序内部                                     | 文件系统中的目录（如 `/bin`, `/usr/bin`, `/sbin` 等） |
| 执行方式 | 由 Shell 直接执行，无需创建新进程                  | Shell 必须通过系统调用启动一个新的进程来执行该文件 |
| 执行速度 | 较快                                               | 较慢（因为涉及进程创建）                          |
| 典型示例 | `cd`, `pwd`, `echo`, `alias`, `export`, `source`   | `ls`, `grep`, `cp`, `mv`, `vim`, `go`              |
| 主要用途 | 改变 Shell 进程的内部状态和环境                    | 执行文件操作、复杂的逻辑处理和系统功能            |

为什么需要内建命令？因为像 `cd` 这样的命令需要直接改变 Shell 进程自身的运行状态（当前工作目录），如果它作为一个独立进程运行，它改变的目录只对它自己有效，而无法影响 Shell 的环境。

我们要学习一个命令，可以通过 `man [命令名]` 来获取它的信息。

### 2.2 目录与文件

#### 2.2.1 目录/文件操作

**`pwd`** ：打印工作目录的绝对路径。

**`cd`** ：改变工作目录

`cd` 命令的常用用法：

| 命令                  | 描述                                                         |
| --------------------- | ------------------------------------------------------------ |
| `cd /path/to/dir`     | 使用绝对路径移动到指定目录。                                 |
| `cd projects/api`     | 使用相对路径移动到当前目录下的子目录。                       |
| `cd ..`               | 移动到当前目录的上一级目录（父目录）。                       |
| `cd .`                | 保持在当前目录（通常用于重新加载环境或查看当前目录文件）。   |
| `cd ~`                | 移动到当前用户的家目录（最常用快捷方式）。                   |
| `cd -`                | 移动到上一次所在的目录。                                     |
| `cd` (不带参数)       | 等同于 `cd ~` ，移动到当前用户的家目录。                     |

**`mkdir`** ：创建新的目录

`mkdir` 命令的基本用法：

| 命令                   | 描述                                             |
| ---------------------- | ------------------------------------------------ |
| `mkdir [目录名]`       | 在当前工作目录下创建单个目录。                   |
| `mkdir /path/to/dir`   | 使用绝对路径或相对路径创建目录。                 |
| `mkdir logs docs assets` | 一次创建多个目录。                               |

`mkdir` 的常用选项：

| 选项 | 描述                                   | 示例                          |
| ---- | -------------------------------------- | ----------------------------- |
| `-p` | 递归创建目录。如果父目录不存在则一并创建。 | `mkdir -p project/src/cmd`    |
| `-m [模式]` | 设置目录的初始权限（模式是八进制数）。 | `mkdir -m 777 temp_dir` (所有人可读写执行) |

#### 2.2.2 文件/目录的查看和管理

**`ls`** :用于列出当前工作目录或指定目录下的文件和子目录。

`ls` 常见用法和选项：

| 命令               | 描述                                                         | 示例              |
| ------------------ | ------------------------------------------------------------ | ----------------- |
| `ls`               | 列出当前目录下的文件和目录（不包括隐藏文件）。               | `ls`              |
| `ls /path/to/dir`  | 列出指定目录的内容。                                         | `ls /etc`         |
| `ls -l`            | 长格式（long format）：显示文件类型、权限、硬链接数、所有者、所属组、大小、修改日期和文件名。 | `ls -l`           |
| `ls -a`            | 显示所有（all）文件，包括以 `.` 开头的隐藏文件（如 `.bashrc` ）。 | `ls -a`           |
| `ls -h`            | 人性化（human-readable）显示文件大小，如 `1.5M` 代替字节数，常与 `-l` 联用。 | `ls -lh`          |
| `ls -t`            | 按修改时间（time）倒序排序（最新修改的在前）。               | `ls -lt`          |
| `ls -R`            | 递归（Recursive）列出子目录中的内容。                        | `ls -R project`   |

**`touch`** 命令主要有两个作用：

1. 如果指定文件名不存在， `touch` 会创建一个大小为零（空）的新文件。
2. 如果指定的文件名已经存在， `touch` 会更新该文件的访问时间和修改时间，但不改变文件内容。

`touch` 命令的常用用法：

| 命令                   | 描述                                               | 示例                      |
| ---------------------- | -------------------------------------------------- | ------------------------- |
| `touch [文件名]`       | 创建新的空文件，或更新现有文件的 atime 和 mtime 为当前时间。 | `touch server.go`         |
| `touch file1 file2 log.txt` | 一次操作多个文件。                                 | `touch config.yml log.txt` |

`touch` 命令高级选项：

| 选项 | 描述                                                         | 示例                                                         |
| ---- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `-a` | 只更新文件的访问时间 (atime)，不更新 mtime。                 | `touch -a logs/access.log`                                   |
| `-m` | 只更新文件的修改时间 (mtime)，不更新 atime。                 | `touch -m main.go`                                           |
| `-c` | 不创建 (no create) 文件。如果文件不存在，不创建新文件，也不报错。 | `touch -c non_exist.txt`                                     |
| `-t [时间]` | 设置指定文件的时间戳为特定的 `[[CC]YY]MMDDhhmm[.ss]` 格式。 | `touch -t 202401011030.00 old_file` (设置为2024年1月1日10点30分0秒) |
| `-r [参考文件]` | 使用另一个参考文件的时间戳来设置目标文件的时间戳。           | `touch -r template.html index.html` (使 index.html 时间戳与 template.html 一致) |

**`cp`** 命令：用于将文件或目录从一个位置复制到另一个位置。

它有三种基本使用场景：

1. 文件 到 文件：将一个文件复制并命名为另一个文件。
2. 文件 到 目录：将一个文件复制到指定的目录下（保留原文件名）。
3. 目录 到 目录：将一个目录及其内容完整地复制到另一个目录中（需要使用递归选项）。

基本语法为：

```bash
cp [选项] [源文件或目录] [目标文件或目录]
```

常见选项有：

| 选项  | 作用  | 开发者场景 |
|-----|-----|-------|
| `-i` | 交互式：在覆盖已存在的文件之前，会提示用户确认（ y/n ）。 | 避免意外覆盖重要文件，建议使用。 |
| `-r` 或 `-R` | 递归：复制目录及其所有子目录和文件。 | 备份整个项目目录时使用。 |
| `-v` | 详细模式：显示正在复制的文件名称。 | 复制大量文件时，提供操作反馈。 |
| `-p` | 保留属性：保留文件的权限、所有者、时间戳等原始属性。 | 备份配置文件或部署文件时，确保权限不丢失。 |
| `-a` | 归档模式：相当于 `-dR --preserve=all` 。确保所有文件属性和符号链接都被正确保留。 | 备份或迁移整个项目时使用。 |
| `-u` | 更新模式：只复制源文件比目标文件新，或者目标文件不存在时才进行复制。 | 同步两个目录的内容，提高效率。 |

`**mv**` ：修改文件的位置或名称

两大作用：


1. 移动（Move）：将文件或目录从一个位置转移到另一个位置。
2. 重命名（Rename）：如果在移动时，目标位置与源文件在同一目录，或者目标文件名与源文件名不同，则实现重命名。

基本语法：

```bash
mv [选项] [源文件或目录] [目标文件或目录]
```

常见选项：

| 选项  | 作用  |
|-----|-----|
| `-i` | 交互式：在覆盖已存在的文件之前，会提示用户确认（ y/n ）。 |
| `-f` | 强制：覆盖已存在的目标文件，不提示。 |
| `-u` | 更新模式：仅当源文件比目标文件新，或者目标文件不存在时才进行移动。 |
| `-v` | 详细模式：显示正在执行的操作。 |

`**rm**` ：删除文件或目录

基本语法：

```bash
rm [选项] [文件或目录]
```

常见选项：

| 选项  | 作用  | 推荐使用场景 |
|-----|-----|--------|
| `-i` | 交互式：在删除每一个文件和目录前，都会提示用户进行确认（ y/n ）。 | 可以避免误删。 |
| `-f` | 强制：忽略不存在的文件，并且不提示确认（即使设置了 `-i` 也会被覆盖）。 | 确定要删除，且不希望被提示打断自动化脚本时使用。 |
| `-v` | 详细模式：显示正在删除的文件名称。 | 删除大量文件时，提供操作反馈。 |
| `-r` | 递归：删除目录及其子文件（空目录也需要）时使用。 | 删除目录树。 |

> **注意：**`**rm -rf /**` **可以删除整个系统！！！执行** `**rm**` **命令之前一定要确认好工作目录。**

`**rmdir**` ：删除空目录的标准和最安全的命令。如果目录不为空， `rmdir` 命令会报错并拒绝删除。

#### 2.2.3 文件权限

我们使用 `ls -l` 命令时，截取的一行输出如下：

```
drwxr-xr-x 2 zhangsan zhangsan 4096 Feb 27 18:53 demo
```

我们来看第一个字段 `drwxr-xr-x` ，这个字段一共有十位，我们按照1 3 3 3进行划分：

| 示例字符 | 位置  | 含义  |
|------|-----|-----|
| `d`  | 第 1 位 | 文件类型：`d` (目录), `-` (普通文件), `l` (符号链接), `s` (套接字文件), `c` (字符设备), `b` (块设备) 等。 |
| `rwx` | 第 2-4 位 | 所有者 (Owner) 的权限：`r` (读), `w` (写), `x` (执行)。 |
| `r-x` | 第 5-7 位 | 所属组 (Group) 的权限：`r` (读), `-` (无写权限), `x` (执行)。 |
| `r-x` | 第 8-10 位 | 其他用户 (Others) 的权限：系统上除所有者和所属组之外的所有用户的权限。 |

每种权限的含义：

* `r` (Read, 读): 允许读取文件内容；对目录而言，允许列出目录下的文件列表。
* `w` (Write, 写): 允许修改或删除文件内容；对目录而言，允许在目录内创建、删除或重命名文件/子目录。
* `x` (Execute, 执行): 允许执行可执行文件（如 Shell 脚本、Go 编译后的程序）；对目录而言，允许进入该目录（ `cd` ）。

我们可以使用 `**chmod**` 命令来修改文件或目录的访问权限， `chmod` 命令有两种使用模式：


1. **符号模式**：使用 `u` (所有者), `g` (组), `o` (其他用户), `a` (所有人) 符号，配合 `+` (增加权限), `-` (移除权限), `=` (设置权限) 操作符。

| 示例命令 | 描述  |
|------|-----|
| `chmod u+x my_script.sh` | 给所有者增加执行 ( `x` ) 权限。 |
| `chmod g-w config.yml` | 移除所属组的写 ( `w` ) 权限。 |
| `chmod a=rwx my_dir` | 设置所有人的权限为读、写、执行（通常不给这么高）。 |
| `chmod go-rw file.txt` | 移除所属组和其他用户的读和写权限。 |


2. **数字模式**：这是更常用、更精确的设置权限方式。每种权限对应一个数值：

* `r` (读) = 4
* `w` (写) = 2
* `x` (执行) = 1
* `-` (无权限) = 0

权限值是这三个数字的总和，然后用三个数字（分别代表所有者、组、其他用户）来表示权限模式，例如：

| 数字模式 | 权限组合 | 描述  |
|------|------|-----|
| 755  | `rwxr-xr-x` | 文件：所有者可读写执行；组和其他人只可读执行。这是可执行程序的常见权限。 |
| 644  | `rw-r--r--` | 文件：所有者可读写；组和其他人只可读。这是配置或文本文件的常见权限。 |
| 700  | `rwx------` | 只有所有者可读写执行。用于私密目录或脚本。 |

示例命令如下：

| 示例命令 | 描述  |
|------|-----|
| `chmod 755 run_server.sh` | 将脚本设置为所有者可读写执行，其他人可读执行。 |
| `chmod 600 id_rsa` | 将私钥文件设置为只有所有者可读写（最严格）。 |
| `chmod -R 770 myapp/` | 递归 ( `-R` ) 地将目录 myapp 及其下所有文件/目录设置为所有者和组可读写执行，其他人无权限。 |

`drwxr-xr-x 2 zhangsan zhangsan 4096 Feb 27 18:53 demo` 第三个字段和第四个字段分别代表文件的所有者（Owner）和所属组（Group），我们可以使用 `chown` 和 `chgrp` 来改变他们，下面介绍这两个命令：


1. `**chown**` **(Change Owner)** 命令用于改变文件或目录的所有者（User Owner）。

| 示例命令 | 描述  |
|------|-----|
| `chown www-data /var/www/html` | 将 `/var/www/html` 目录的所有者改为 `www-data` 用户。 |
| `chown -R zhangsan myapp/` | 递归 ( `-R` ) 地将 myapp 目录及其所有内容的所有者改为 zhangsan 用户。 |
| `chown user:group file.txt` | 同时改变文件所有者和所属组。 |


2. `**chgrp**` **(Change Group)** 命令用于改变文件或目录的所属组（Group Owner）。

| 示例命令 | 描述  |
|------|-----|
| `chgrp docker /var/run/docker.sock` | 将 Docker 套接字文件的所属组改为 docker 组。 |
| `chgrp -R developers myapp/` | 递归 ( `-R` ) 地将 myapp 目录及其所有内容的所属组改为 developers 组。 |

#### 2.3.2 强大的搜索工具 grep

作用：在一个或多个文件中，搜索匹配指定的行，并将匹配到的行打印到标准输出。

基本语法：

```bash
grep [选项] [模式] [文件名...]
```

常见选项：

| 选项  | 作用  | 示例  |
|-----|-----|-----|
| `-i` | 忽略大小写。搜索时，不区分大小写。 | `grep -i "fatal" log.txt` |

| `-r` | 递归搜索。搜索指定目录及其所有子目录下的文件。 | `grep -r "myFunction" project_dir/` |
| `-c` | 计数。不打印匹配的行，只输出匹配的总行数。 | `grep -c "GET /api" access.log` |
| `-l` | 只列出包含匹配项的文件名，不打印匹配的内容。 | `grep -l "password" *` |
| `-E` | 开启拓展正则表达式。 | `grep -E "^func.*$" *.go` |

**补充：正则表达式由三部分组成：**


1. 字面量字符：大部分字符代表它们本身
2. 元字符：代表某种规则或操作

| 元字符 | 含义  | 示例  | 匹配结果 |
|-----|-----|-----|------|
| `.` (点) | 匹配任意一个字符（换行符除外）。 | `g.t` | 匹配 "got", "gat", "g!t" 等。 |
| `*` | 匹配前面的元素零次或多次。 | `go*` | 匹配 "g", "go", "goo", "gooo" 等。 |
| `+` | 匹配前面的元素一次或多次。 | `go+` | 匹配 "go", "goo" 等，但不匹配 "g"。 |
| `?` | 匹配前面的元素零次或一次（可选）。 | `go?t` | 匹配 "got" 或 "gt"。 |
| `^` | 匹配字符串的开头。 | `^Error` | 匹配以 "Error" 开头的行。 |
| `$` | 匹配字符串的结尾。 | `\.go$` | 匹配以 ".go" 结尾的文件名。 |
| `[]` | 字符集：匹配方括号内的任意一个字符。 | `[0-9]` | 匹配任意一个数字。 |
| `()` | 分组：用于捕获匹配或应用量词。 | `(Go){2}` | 匹配 "GoGo"。 |
| `\` | 转义符：将元字符转为字面量，或字面量转为特殊序列。 | `\.` | 匹配字面量点 `.`。 |


3. 特殊序列：使用转义符 `\` 来表示常用的字符集

| 序列  | 含义  | 示例  |
|-----|-----|-----|
| `\d` | 匹配任意一个数字 (等同于 `[0-9]` )。 | `\d+` |
| `\w` | 匹配任意一个单词字符（字母、数字、下划线）。 | `\w{3}` |
| `\s` | 匹配任意一个空白字符（空格、Tab 键等）。 | `\s*` |

#### 2.3.3 Vim

Vim 是 Vi Improved 的缩写，它是一个高度可配置、高效的文本编辑器。它是 Unix-like 系统（包括 Linux、macOS）上最古老、最强大、也是最受欢迎的文本编辑器之一。

Vim核心思想是模式化编辑，它通过键盘命令在不同的"模式"之间切换来执行不同的功能，这是 Vim 高效的核心所在，因为你的手几乎不需要离开键盘。

**Vim的四个核心模式：**

| 模式名称 | 作用  |
|------|-----|
| 1. 普通模式 | 核心模式。用于在文件内导航、删除、复制、粘贴、以及切换到其他模式。 |
| 2. 插入模式 | 用于输入和编辑文本，像普通编辑器一样。 |
| 3. 命令模式 | 用于执行复杂命令，如保存文件、退出、搜索、替换、以及配置 Vim。 |
| 4. 可视模式 | 用于选择文本块，然后对所选区域进行操作（如复制、删除、替换等）。 |

Vim 的强大之处在于其动词-名词的命令结构，可以像组装句子一样组合命令：

```text
[数字] + [动词/操作] + [名词/对象]
```

| 元素类型 | 常见命令 | 含义  |
|------|------|-----|
| 动词/操作 | `d` (Delete) | 删除  |
|      | `y` (Yank) | 复制 (拷贝) |
|      | `c` (Change) | 改变 (删除并进入插入模式) |
| 名词/对象 | `w` (Word) | 一个单词 |
|      | `$`  | 到行尾 |
|      | `t` (Tag) | 某个字符之前 |
|      | `p` (Paste) | 粘贴  |

如：

| 组合命令 | 含义  |
|------|-----|
| `dw` | 删除一个单词。 |
| `d$` | 删除从光标位置到行尾的内容。 |
| `3yy` | 复制当前行和下面的两行，共三行。 |
| `ci"` | 改变引号内的内容。 |

**Vim普通模式下常用操作表：**

| 操作  | 命令 (在普通模式下) | 描述  |

### 2.4 软件安装的三种方式

#### 2.4.1 包管理器安装（推荐）

这是 Linux 最推荐、最安全、最方便的软件安装方式。它是一个完整的系统，负责自动处理软件的依赖关系、安装、配置、更新和卸载。

不同Linux发行版家族使用不同的管理工具：

**1. Debian/Ubuntu 家族 (使用 .deb 格式包)**

* 底层工具：`dpkg` (Debian Package)：用于处理单个 `.deb` 文件的安装和卸载。
* 高级工具：`apt` (Advanced Package Tool)：最常用、功能最强大的工具，它能自动解决软件包之间的复杂依赖关系，并从配置的软件源 (Repository) 下载安装。

| 命令  | 作用  | 示例  |
|-----|-----|-----|
| `sudo apt update` | 更新本地软件包索引（必须先运行）。 | `sudo apt update` |
| `sudo apt install [pkg]` | 安装指定软件。 | `sudo apt install nginx` |
| `sudo apt remove [pkg]` | 卸载指定软件（保留配置文件）。 | `sudo apt remove go` |
| `sudo apt upgrade` | 升级所有已安装的软件包。 | `sudo apt upgrade` |

**2. Red Hat/CentOS/Fedora 家族 (使用 .rpm 格式包)**

* 底层工具：`rpm` (Red Hat Package Manager)：用于处理单个 `.rpm` 文件。
* 高级工具：`yum` / `dnf` ：
  * `yum` (Yellowdog Updater, Modified)：历史上的主要工具。
  * `dnf` (Dandified Yum)：现代 Fedora/新版 CentOS/RHEL 中取代 `yum` 的新一代工具，功能更强大。

| 命令  | 作用  | 示例  |
|-----|-----|-----|
| `sudo dnf check-update` 或 `yum check-update` | 检查可更新的软件包。 | `sudo dnf check-update` |
| `sudo dnf install [pkg]` | 安装指定软件。 | `sudo dnf install mysql-server` |
| `sudo dnf remove [pkg]` | 卸载指定软件。 | `sudo dnf remove php` |

#### 2.4.2 手动二进制文件/安装包安装

当你要安装某些特定的第三方工具时，官方通常提供一个 `.tar.gz` 压缩包，里面是编译好的二进制文件。

步骤：


1. 下载 `.tar.gz` 文件。
2. 解压缩到目标路径（通常是 `/usr/local/` ）。
3. 手动将可执行文件路径添加到系统的 `$PATH` 环境变量中。

#### 2.4.3 从源代码编译安装（了解即可）

这是最传统的 Linux 安装方式，现在主要用于安装非常小众的工具，或者需要定制编译选项时。

步骤：


1. 解压源代码包。
2. 运行 `./configure` 命令（检查系统环境和依赖）。
3. 运行 `make` 命令（编译）。
4. 运行 `sudo make install` 命令（安装到系统目录）。

### 2.5 进程

进程是 Linux 操作系统的核心概念。当你运行你的 Go 程序或任何一个 Linux 命令时，操作系统都会为其创建一个或多个进程来执行任务。

进程是程序的一次执行过程。它不仅仅是代码本身，还包括程序执行时所需的资源，如：

* 程序代码：二进制执行文件。
* 内存空间：栈、堆、数据和代码段。
* 系统资源：文件描述符（打开的文件、网络套接字等）。
* 状态信息：进程 ID (PID)、状态、优先级等。

**关键标识符:**

* PID (Process ID)：进程的唯一标识符。
* PPID (Parent Process ID)：启动当前进程的父进程的 ID。
* UID/GID：进程运行时的用户 ID 和用户组 ID，决定了进程的权限。

**进程状态**

| 状态  | 含义  | 符号  |
|-----|-----|-----|
| R Running (运行) | 进程正在 CPU 上运行，或等待被调度运行。 | R   |
| S Sleeping (睡眠) | 进程正在等待某个事件完成（如 I/O 操作、网络数据到达）。这是大多数后台服务的常见状态。 | S   |
| D Disk Sleep (不可中断睡眠) | 进程在等待磁盘 I/O 完成，此时无法被信号中断（通常是 I/O 故障导致）。 | D   |
| T Stopped (停止) | 进程被暂停（如通过 Ctrl+Z 或 `kill -STOP` ）。 | T   |
| Z Zombie (僵尸) | 进程已终止，但其父进程还没有读取它的退出状态。它不占用内存，只占用 PID。 | Z   |

**核心进程管理命令**

| 类别  | 命令  | 作用描述 | 常用选项或组合 | 典型应用场景 |
|-----|-----|------|---------|--------|
| 状态查看 | `ps` | 显示当前系统进程的静态快照信息。 | `ps aux` / `ps -ef` | 查看系统上所有进程的详细信息和启动参数。 |
| 实时监控 | `top` | 实时显示系统资源（CPU、内存）占用和进程状态的动态视图。 | (默认即可)  | 快速诊断哪个进程造成 CPU 或内存负载过高。 |
| 实时监控 | `htop` | 增强版 `top` ，界面更友好，支持鼠标操作。 | (默认即可)  | 比 `top` 更直观地监控和管理进程。 |
| 信号控制 | `kill` | 向指定 PID 的进程发送信号，控制其行为。 | `kill [PID]` (默认 SIGTERM) | 优雅关闭进程。 |
|     | `kill -9 [PID]` | 强制杀死无响应或僵尸进程（非必要不推荐）。 | `kill -9 [PID]` (SIGKILL) | 强制终止。  |
| 进程查找 | `pgrep` | 根据名称或其他属性查找进程 PID，配合 `kill` 使用。 | `pgrep [名称]` | 快速获取进程的 PID。 |
| 后台管理 | `jobs` | 列出当前 Shell 会话中在后台运行的进程（挂起的任务）。 | `jobs`  | 查看在当前终端中被 `&` 符号或 Ctrl+Z 挂起的任务。 |
| 后台管理 | `fg` | 将后台进程切换到前台运行。 | `fg [job_id]` | 恢复对后台运行服务的控制。 |
| 进程启动 | `&` | 命令末尾加 `&` ，使命令在后台运行。 | `go run main.go &` | 启动一个进程进行测试，同时保持终端可用。 |

### 2.6 用户相关命令

#### 2.6.1 核心概念

**用户与用户组**

* **用户 (User)**：每个人或每个系统服务都有一个用户账户。每个用户由一个唯一的用户ID (UID) 标识。
* **用户组 (Group)**：一组用户的集合。用户组由一个唯一的组ID (GID) 标识。组权限通常用于控制对资源的访问，例如只有 `docker` 组的用户才能访问 Docker 套接字文件。
* **主组 (Primary Group)**：用户登录时所属的默认组。
* **附属组 (Secondary Group)**：用户同时属于的其他组。

**关键文件：**

* `/etc/passwd` ：存储所有用户账户的基本信息（用户名、UID、默认Shell、家目录等）。注意：密码哈希值不在这里。
* `/etc/shadow` ：存储用户的密码哈希值和密码过期信息。只有 root 用户可读，保障安全。
* `/etc/group` ：存储所有用户组的信息（组名、GID、组成员列表）。

#### 2.6.2 用户管理命令

| 命令  | 作用  | 示例  |
|-----|-----|-----|
| `useradd` | 创建新用户账户。 | `sudo useradd -m newuser` |
| `passwd` | 设置或更改用户密码。 | `sudo passwd newuser` |
| `usermod` | 修改用户账户属性（如更改家目录、UID、加入新组）。 | `sudo usermod -aG docker zhangsan` |
| `userdel` | 删除用户账户。 | `sudo userdel -r olduser` |
| `id` | 显示当前或指定用户的 UID、GID 和所属组信息。 | `id` 或 `id zhangsan` |
| `whoami` | 显示当前登录的用户名。 | `whoami` |
| `su` | 切换用户 (Substitute User)。 | `su - newuser` |
| `sudo` | 以另一个用户（通常是 root）的身份执行命令。 | `sudo apt update` |

#### 2.6.3 用户组管理命令

| 命令  | 作用  | 示例  |
|-----|-----|-----|
| `groupadd` | 创建新用户组。 | `sudo groupadd developers` |
| `gpasswd` | 管理组成员（更灵活）。 | `sudo gpasswd -a zhangsan developers` |
| `groupdel` | 删除用户组。 | `sudo groupdel oldgroup` |
| `groups` | 显示当前用户所属的所有组。 | `groups` |

## 3 实战：在Linux上部署一个go项目

### 3.1 方法一：交叉编译

原理：利用 Go 语言强大的交叉编译能力。Go 编译器允许你在一个平台上（如 Windows/amd64）生成另一个平台（如 Linux/amd64）的机器码。

步骤：


1. 我们以一个简单的gin演示项目为例，先在windows中创建一个文件夹 `gin-demo` ，完成项目的初始化后创建一个 `main.go` 并输入以下代码，记得要保存。

```go
package main

import "github.com/gin-gonic/gin"

func main() {
    router := gin.Default()
    router.GET("/", func(c *gin.Context) {
        c.JSON(200, gin.H{"message": "Hello, World!"})
    })
    router.Run(":8080")
}
```


2. 在终端（powershell）中输入：

```powershell
$env:GOOS = "linux"     # 设置目标操作系统为 Linux
$env:GOARCH = "amd64"   # 设置目标架构为 AMD64，如果本来就是 AMD64 就不用管
go build -o linux-gin-demo main.go   # 表示编译 main.go，生成一个叫 linux-gin-demo 的二进制文件
```

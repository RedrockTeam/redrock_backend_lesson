# 红岩网校 Go 入门课件

本目录是教师用课件，独立 Git 仓库。四课均按“现象 → 概念 → 最小代码 → 测试 → 练习复盘”组织，练习 starter 在相邻的 `../exercises` 仓库。

| 文件 | 主题 |
| --- | --- |
| `lesson-01-basics.md` | 社团后端、Git/GitHub 与 Go 基础 |
| `lesson-02-collections.md` | map、interface 与可扩展数据结构 |
| `lesson-03-goroutines.md` | 计算机基础与 goroutine |
| `lesson-04-sync.md` | channel、sync、锁与 worker pool |
| `recording-live.md` | OBS、Bilibili、隐私与演练 |

讲师每课只需保留一个现场编码主线；其余例子作为备用，避免直播节奏被 API 细节打断。
